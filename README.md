# Boodschappenlijst

Gedeelde boodschappen- en vakantielijsten voor thuis, als installeerbare app.

- De app draait op GitHub Pages: https://mchielsen.github.io/boodschappenlijst/
- De lijsten zelf staan **niet** in deze repository, maar in de privé-repository
  `mchielsen/boodschappenlijst-data` (bestand `data.json`).
- Inloggen gaat met je naam en de gezamenlijke sleutel (een fine-grained token met
  alleen toegang tot `boodschappenlijst-data`, Contents: lezen en schrijven).

## Op de telefoon zetten
- Android (Chrome): menu ⋮ > "App installeren" of "Toevoegen aan startscherm"
- iPhone (Safari): Deel-knop > "Zet op beginscherm"
